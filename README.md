# Deobfuscated Roblox Scripts Collection

Koleksi lengkap skrip Roblox yang sudah dideobfuskasi & dibersihkan dari proteksi VM / Luau obfuscator (HipHub, NodeHub, WisHub, DuckHub). Repository ini siap digunakan langsung di executor Roblox mana pun (Synapse, Wave, Codex, Delta, Fluxus, dll) dengan anti-cache parameter (`?t=" .. tostring(tick())`).
